================================================================================
横滚 PID 一拍：修复前 vs 修复后
================================================================================

输入：横滚角 = +8.0°（右倾），目标 = 0.0°，kp=20, ki=0, kd=0, limit=20
      dive_left=12.0%%, dive_right=23.0%%  (截图值)

  P 项 = kp × (roll - target) = 20 × 8.0 = 160.0
  限幅到 ±20  =>  corr = +20.0 %

【修复前】corr 只存内存，不下发：
  ch8 实际输出 = 12.0 %   (冻结在按下『下潜』那一刻的 12.0)
  ch9 实际输出 = 23.0 %   (冻结在 23.0)
  ==> 无论 sign=+1 还是 -1，电机输出**完全一样**，所以看不出任何纠偏。

【修复后】corr 每 100ms 写出去：
  sign=+1: corr=+20.0% -> ch8= 32.0%  ch9=  3.0%   (差动 +29.0%)
  sign=-1: corr=-20.0% -> ch8= -8.0%  ch9= 43.0%   (差动 -51.0%)

  结论：sign 现在**真的有效**了，且两个方向恰好相反。

================================================================================
目标角语义验证（标定后以当前横滚角为目标）
================================================================================

场景：艇横滚 5°，此时按「重新标定」-> target_roll = 5°
  当前 5°、目标 5° -> 误差 0 -> corr = +0.0%  (零修正，正确保持)

之后艇漂到 10°（偏离基准 5°）:
  误差 = 10 - 5 = 5° -> corr = +20.0%  (朝基准方向拉回)

对照：未标定（target=0）时漂到 10°:
  误差 = 10 - 0 = 10° -> corr = +20.0%  (要求彻底水平)

================================================================================
附带发现：kp=20 + limit=20 时，P 项 8° 就已饱和
================================================================================
  倾角  0.5° -> P=  10.0 -> corr=+10.0%  
  倾角  1.0° -> P=  20.0 -> corr=+20.0%  饱和
  倾角  2.0° -> P=  40.0 -> corr=+20.0%  饱和
  倾角  5.0° -> P= 100.0 -> corr=+20.0%  饱和
  倾角 20.0° -> P= 400.0 -> corr=+20.0%  饱和

  → 只要倾角 ≥ 1.0° 就顶到上限。灵敏度很高，
    调试时建议先把 kp 降到 1~3 观察，或把 limit 保留小一点防过冲。
